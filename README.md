# bagllet — قالب اختصاصی وردپرس

بازسازی ظاهر و رفتار سایت bagllet.ir (فروشگاه چرم) به‌صورت یک قالب وردپرس مستقل و قابل فروش.

## ساختار (هم‌ریخت با `public_html` روی هاست)
```
public_html/wp-content/
  plugins/bagllet-widgets/   پلاگین همراه فعلی (ویجت‌های المنتور، صفحات درباره/تماس، فوتر و استایل‌ها)
  themes/bagllet/            قالب جدید (در حال ساخت)
docs/                        نقشه‌راه، پروتکل بازبینی، وضعیت فازها
.cursor/rules/               قواعد ایجنت
شناسنامه استایل bagllet.ir.md   توکن‌های طراحی (رنگ، فونت، مقیاس‌ها)
```

## شروع
1. `docs/THEME-ROADMAP.md` را کامل بخوان.
2. روند تحویل/بازبینی: `docs/REVIEW-PROTOCOL.md`.
3. وضعیت فازها: `docs/PROGRESS.md`. کار از **فاز ۰** شروع می‌شود.
