قالب فروشگاهی اختصاصی برای بازسازی ظاهر bagllet.ir بدون Woodmart.

== Description ==
رنگ، فونت و فاصله فقط از CSS variables (`tokens.css`). فونت پیش‌فرض بسته‌ی فروش: Vazirmatn (OFL). فونت‌های تجاری سایت زنده از طریق آپلود سفارشی لود می‌شوند و داخل zip فروش نیستند.

این قالب برای فروشگاه‌های RTL/فارسی طراحی شده است؛ جهت صفحه از تنظیمات زبان وردپرس (`language_attributes` / `is_rtl`) می‌آید.
