== Description ==
رنگ، فونت و فاصله فقط از CSS variables (`tokens.css`). فونت پیش‌فرض بسته‌ی فروش: Vazirmatn (OFL). فونت‌های تجاری سایت زنده از طریق آپلود سفارشی لود می‌شوند و داخل zip فروش نیستند.
