# فهرست افزونه‌ها و ارتباط با ظاهر (فاز ۱)

> نسخه‌های دقیق و افزونه‌های غیرظاهری (پشتیبان/کش/امنیتی) فقط در `qa/data/` (ignore) نگه داشته می‌شوند. اینجا فقط نقش ظاهری.

قالب فعال فرانت: **Woodmart** (child ندارد).

| نقش | ارتباط با ظاهر | مهاجرت |
|---|---|---|
| ووکامرس | فروشگاه، کارت، محصول، سبد، تسویه، حساب | الزامی |
| Elementor (+ Pro) | صفحه‌ی اصلی و برخی قالب‌ها | هدر/فوتر مستقل؛ صفحه اصلی اختیاری |
| Woodmart Core | CPT/متا، قابلیت‌های هسته | جایگزین در قالب/پلاگین همراه |
| وودمارت پلاس (راستچین) | RTL، حساب کاربری سفارشی، بسته‌ی بازار | حذف پس از parity؛ RTL در قالب |
| bagllet-widgets | ویجت‌های المنتور، درباره/تماس، فوتر/استایل | می‌ماند؛ تمیز از Woodmart |
| بهینه‌ساز عملکرد (کش/asset) | ممکن است CSS/JS را تغییر دهد | در QA در نظر گرفته شود؛ داخل zip فروش نیست |
| ادیتور کلاسیک / ویجت کلاسیک | بدون اثر ظاهر فرانت فروشگاهی | — |
| WP Story | استوری (در صورت استفاده در DOM) | در features پیگیری |
| مراقبت لایسنس/RTL بازار | غیرضروری پس از parity | — |
| ورود/پیامک (در صورت فعال) | فرم ورود موبایل، تیکت/پیامک | خارج از قالب فروش (یکپارچه‌سازی اختیاری) |

جزئیات نسخه و مسیر فایل‌ها: `qa/data/ftp/` و `qa/data/export/` (ignore).
