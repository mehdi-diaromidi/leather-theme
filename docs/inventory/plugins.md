# فهرست افزونه‌ها و ارتباط با ظاهر (فاز ۱)

منبع: لیست FTP `wp-content/plugins/` + هدر فایل اصلی + مشاهده‌ی DOM زنده.  
قالب فعال: **Woodmart 8.5.5** (`wp-content/themes/woodmart`).

| پوشه | نام / نسخه | نقش ظاهری / DOM | مهاجرت |
|---|---|---|---|
| `woocommerce` | WooCommerce **11.2.2** | فروشگاه، کارت، محصول، سبد، تسویه، حساب | الزامی؛ قالب جدید باید سازگار باشد |
| `elementor` | Elementor **4.4.0** | صفحه‌ی اصلی و احتمالاً برخی صفحات | هدر/فوتر نباید وابسته بماند؛ صفحه اصلی اختیاری |
| `elementor-pro` | Elementor Pro **4.4.0** | امکانات پرو / قالب‌ها | وابستگی سخت برای قالب فروش ممنوع (جز صفحه اصلی) |
| `woodmart-core` | Woodmart Core **1.1.7** | CPT/متا، قابلیت‌های هسته Woodmart | جایگزین در قالب/پلاگین همراه |
| `woodmart-plus` | وودمارت پلاس راستچین **5.8.9** | RTL و بسته‌ی بازار فارسی | حذف پس از parity؛ RTL در قالب خودمان |
| `bagllet-widgets` | Bagllet Widgets **1.14.45** | ویجت‌های المنتور، درباره/تماس، فوتر/استایل‌های فعلی | می‌ماند؛ بعداً تمیز و مستقل از Woodmart |
| `wp-rocket` | WP Rocket **3.24** | کش/بهینه | ظاهر مستقیم ندارد؛ در QA کش را در نظر بگیر |
| `perfmatters` | Perfmatters **2.6.9** | غیرفعال‌سازی دارایی‌ها | ممکن است CSS/JS را تغییر دهد |
| `classic-editor` | Classic Editor **1.7.0** | ادیتور | بدون اثر ظاهر فرانت |
| `classic-widgets` | Classic Widgets **0.3** | ویجت‌های کلاسیک | کم‌اثر روی فرانت فروشگاهی |
| `wp-story` | WP Story **2.1.2** | استوری | اگر در صفحه اصلی/جاهای دیگر استفاده شده در features پیگیری شود |
| `duplicator` | Duplicator **5.1.1** | پشتیبان/مهاجرت | بدون اثر ظاهر |
| `RTL-CareUnit` | افزونه مدیریت هوشمند راست چین **2.6.7** (فعال) | مراقبت لایسنس/RTL راستچین | پس از parity احتمالاً غیرضروری |
| `plugin` | روی FTP بود؛ در `active_plugins` نیست | غیرفعال/زاید | نادیده برای ظاهر |

## mu-plugins

در ابتدا پوشه وجود نداشت؛ برای صادرات موقت `mu-plugins/bagllet-export.php` ایجاد/آپلود می‌شود و پس از دریافت JSON **حذف** می‌گردد.

## نسخه‌ی محیط (از export JSON در صورت موفقیت)

پس از اجرای mu-plugin در `qa/data/export/bagllet-export.json` ثبت می‌شود (ignore). خلاصه در handoff.
